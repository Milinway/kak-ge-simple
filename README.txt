WEBSITE ULANG TAHUN KAK GE — VERSI SIMPLE
=========================================

Tidak perlu install apa pun.
Tidak ada npm, React, Vite, TypeScript, node_modules, atau build.

CARA MENJALANKAN
----------------
1. Extract folder ini.
2. Buka index.html langsung di browser, ATAU klik "Open with Live Server" di VS Code.
3. Selesai.

CARA MASUKIN FOTO
-----------------
Masukkan foto ke folder:
assets/photos/

Nama file yang sudah disiapkan:
- hero.jpg        = foto utama Kak GE
- memory-01.jpg
- memory-02.jpg
- memory-03.jpg
- memory-04.jpg
- memory-05.jpg
- memory-06.jpg
- memory-07.jpg
- memory-08.jpg
- memory-09.jpg
- memory-10.jpg
- memory-11.jpg
- fun-01.jpg
- fun-02.jpg
- fun-03.jpg

Kamu BOLEH pakai ekstensi:
.jpg / .jpeg / .png / .webp

Contoh:
assets/photos/hero.png
assets/photos/memory-01.webp

Tidak perlu ubah HTML. script.js otomatis mencari ekstensi foto yang tersedia.

Kalau ingin mengganti teks, semuanya ada di index.html.
Kalau ingin mengganti warna/layout, edit style.css.

STRUKTUR
--------
index.html      -> semua isi website
style.css       -> semua tampilan
script.js       -> menu HP + auto-detect foto
assets/photos/  -> tempat kamu menaruh foto
